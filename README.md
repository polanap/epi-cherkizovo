# Сайт благотворительного фонда «Черкизово»

Учебный проект по дисциплине «Экономика программной инженерии» (ЛР 2).
Задачи ведутся в YouTrack, проект CHE: https://cherkizovo.youtrack.cloud

## Ветки
- `main` — стабильные релизы (теги `v0.1`, `v0.5`, `v1.0`)
- `develop` — интеграционная ветка
- `feature/CHE-<номер>-<описание>` — разработка задачи
- `bugfix/CHE-<номер>-<описание>` — исправление ошибки
- `release/<версия>` — подготовка релиза

В сообщении коммита обязательно указывается ID задачи YouTrack, например `CHE-118 Главная страница`.
